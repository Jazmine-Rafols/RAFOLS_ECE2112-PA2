## **A. Reproducible Normalization Problem**
> Instructions: Create a reproducible random 5x5 integer ndarray named `X`. Normalize array `X` using the mean normalization formula, where the program shall get the mean of all 25 elements and the standard deviation to be stored in the variable `X_normalized`. Display array `X`, `X_normalized`, its mean, and its standard deviation with up to floating point rounding. 

The problem states that a reproducible random 5x5 ndarray should be created to be called as ndarray `X`. This can be created through using the NumPy library, in which it shall be initialized as:
```python
Import numpy as np
```
Now that NumPy has been initialized, the reproducible randomized array can be generated by using these two statements,
```python
np.random.seed(2112)
X = np.random.randint(10,101,size=(5,5))
```
Utilizing the `np.random.seed(2112)` means that any randomly generated numbers to create the 5x5 ndarray will guarantee that every simulation of this line of code will generate and retain the exact same matrix to use throughout.

The second line, `X = np.random.randint(10,101, size=(5,5))`, pertains to the size or dimensions of the ndarray. These are indicated by `10` as its lowest possible integer that is inclusive, `101` as its highest possible integer but is exclusive of 101, then `size=(5,5)` refers to the shape of the array.

When these cells are executed, it will output a reproducible randomized 5x5 array as expected. For this problem, it provided the ndarray below:
```python
X = [[48  11  15  67  21]
     [11  41  13  66  24]
     [71  79  53  67  70]
     [77  45  91  19  96]
     [35  54  37  41  17]]
```
### Solution to the Problem

Following the generated array, the problem asks that the program should normalize the complete array using the **mean normalization formula**, which is array `X` subtracted by the mean then divided by its standard deviation. 

Firstly, to acquire the mean and the standard deviation, it can be executed by using Numpy’s `X.mean()` and `X.std()` default calls. However, the mean and the standard deviation must be in floating point rounding form, whose syntax is `np.round()`. The complete syntax is shown below where the corresponding outputs would be `46.0` and `25.9`, respectively.
```python
print(np.round(X.mean(),0))
print(np.round(X.std(),1))
```
Given that the mean and standard deviation are now solved for, the formula can be executed under the variable name `X_normalized` and the cell is written as:
```python
X_normalized = (X - X.mean()) / X.std()
print(X_normalized)
```
A normalized array should be returned as the result. Through the given normalized array, the normalized mean and normalized standard deviation can be computed similarly to the initial syntax except, instead of using X as the array, X_normalized is the array present. The correct outputs should be `0.0` and `1.0` for the normalized mean and standard deviation, respectively.
```python
print(np.round(X_normalized.mean(),0))
print(np.round(X_normalized.std(),1))
```
After this, the normalized array is saved through this syntax,
```python
np.save("X_normalized.npy", np.ndarray)
```
